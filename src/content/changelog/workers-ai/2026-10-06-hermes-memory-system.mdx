## What's Included

### Four-Layer Memory Architecture
- **Layer 1: Episodic Memory** (Cloudflare D1) - Stores every decision and outcome
- **Layer 2: Semantic Memory** (D1 + embeddings) - Facts, rules, and learned patterns
- **Layer 3: Procedural Memory** (D1 + KV cache) - Successful workflows and patterns
- **Layer 4: Task State** (Workers KV) - In-progress work with checkpointing
