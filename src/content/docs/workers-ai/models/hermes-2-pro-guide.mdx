Hermes 2 Pro is a fine-tuned 7B parameter model optimized for function calling, structured output generation, and instruction-following. This guide helps you determine if Hermes 2 Pro is the right choice for your use case and shows you how to implement it effectively in production.

## Quick Overview

| Aspect | Details |
|--------|---------|
| **Model ID** | `@hf/nousresearch/hermes-2-pro-mistral-7b` |
| **Base Model** | Mistral 7B |
| **Context Window** | 24,000 tokens |
| **Specialization** | Function calling, JSON mode, instruction-following |
| **Ideal For** | Agents, tool-use applications, data extraction |
| **Size** | 7B parameters (efficient on Cloudflare's infrastructure) |

## When to Use Hermes 2 Pro

### ✅ Use Hermes 2 Pro When:

- **Building AI agents** that need to call external functions or APIs
- **Extracting structured data** from unstructured text
- **Generating guaranteed JSON output** for database inserts or API calls
- **Following complex instructions** with high precision
- **Running multi-step reasoning** with function calls
- **Cost-conscious** about inference (smaller model = lower cost)
- **Need low latency** with reasonable quality

### ❌ Consider Alternatives When:

- **Extreme accuracy required** for complex reasoning → Use Llama 3.1 70B
- **Image understanding needed** → Use Llama 3.2 Vision models
- **Summarization focus** → Use specialized models or smaller variants
- **Budget is unlimited** → Larger models may have marginal quality gains
- **Real-time streaming** with complex logic → Higher performance models needed

## Production Patterns

### Pattern 1: API-Powered Agent

Route user requests to the correct API using function calling:

```typescript
import { Ai } from "@cloudflare/workers-types";

interface Env {
  AI: Ai;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const { userQuery } = await request.json() as { userQuery: string };

    const tools = [
      {
        name: "search_knowledge_base",
        description: "Search internal documentation for answers",
        parameters: {
          type: "object",
          properties: {
            query: { type: "string", description: "Search query" },
            limit: { type: "number", description: "Number of results" },
          },
          required: ["query"],
        },
      },
      {
        name: "create_support_ticket",
        description: "Create a support ticket for complex issues",
        parameters: {
          type: "object",
          properties: {
            issue: { type: "string" },
            priority: { type: "string", enum: ["low", "medium", "high"] },
            category: { type: "string" },
          },
          required: ["issue"],
        },
      },
    ];

    const response = await env.AI.run(
      "@hf/nousresearch/hermes-2-pro-mistral-7b",
      {
        messages: [
          {
            role: "system",
            content: "You are a helpful support assistant. Route requests appropriately.",
          },
          {
            role: "user",
            content: userQuery,
          },
        ],
        tools,
      }
    );

    // Handle tool calls
    if (response.tool_calls && response.tool_calls.length > 0) {
      const results = [];
      for (const call of response.tool_calls) {
        const result = await executeToolCall(call.name, call.arguments);
        results.push({ tool: call.name, result });
      }
      return new Response(JSON.stringify({ status: "success", tools_executed: results }));
    }

    return new Response(JSON.stringify({ response: response.response }));
  },
};

async function executeToolCall(
  name: string,
  args: Record<string, unknown>
): Promise<unknown> {
  // Implement actual tool execution
  if (name === "search_knowledge_base") {
    return { results: ["..."], found: true };
  }
  return { executed: true };
}
```

### Pattern 2: Structured Data Extraction

Extract and validate data using JSON Mode:

```typescript
interface Env {
  AI: Ai;
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const { text } = await request.json() as { text: string };

    const response = await env.AI.run(
      "@hf/nousresearch/hermes-2-pro-mistral-7b",
      {
        messages: [
          {
            role: "system",
            content: "Extract structured data from the provided text. Return valid JSON only.",
          },
          {
            role: "user",
            content: text,
          },
        ],
        response_format: {
          type: "json_object",
        },
        max_tokens: 1024,
        temperature: 0.1, // Low temperature for consistent extraction
      }
    );

    try {
      const extracted = JSON.parse(response.response);
      return new Response(
        JSON.stringify({ success: true, data: extracted }),
        { status: 200 }
      );
    } catch {
      return new Response(
        JSON.stringify({ success: false, error: "Invalid JSON output" }),
        { status: 400 }
      );
    }
  },
};
```

### Pattern 3: Multi-Turn Conversation with State

Build stateful conversations with persistent context:

```typescript
interface Message {
  role: "user" | "assistant" | "system";
  content: string;
}

interface ConversationState {
  messages: Message[];
  context: Record<string, unknown>;
}

async function continueConversation(
  state: ConversationState,
  userMessage: string,
  env: Env
): Promise<{ reply: string; updatedState: ConversationState }> {
  const newMessages: Message[] = [
    ...state.messages,
    { role: "user", content: userMessage },
  ];

  const response = await env.AI.run(
    "@hf/nousresearch/hermes-2-pro-mistral-7b",
    {
      messages: newMessages,
      max_tokens: 512,
      temperature: 0.7,
    }
  );

  const assistantMessage: Message = {
    role: "assistant",
    content: response.response,
  };

  return {
    reply: response.response,
    updatedState: {
      messages: [...newMessages, assistantMessage],
      context: state.context,
    },
  };
}
```

## Optimization Guide

### Temperature Settings

| Temperature | Use Case | Example |
|-------------|----------|---------|
| **0.1-0.3** | Deterministic extraction, JSON generation | Data parsing, extraction |
| **0.5-0.7** | Balanced creativity (default) | General conversations, assistance |
| **0.8-1.0** | Creative tasks | Brainstorming, content generation |

For Hermes specifically, use **0.1-0.3** for function calling to ensure consistency.

### Context Management

With 24,000 tokens available:

```typescript
// Strategy 1: Truncate old messages
function trimOldMessages(messages: Message[], maxMessages = 10): Message[] {
  return messages.slice(-maxMessages);
}

// Strategy 2: Summarize conversation history
async function summarizeHistory(
  messages: Message[],
  env: Env
): Promise<string> {
  const response = await env.AI.run(
    "@hf/nousresearch/hermes-2-pro-mistral-7b",
    {
      messages: [
        {
          role: "system",
          content: "Summarize the key points of this conversation.",
        },
        {
          role: "user",
          content: messages.map((m) => `${m.role}: ${m.content}`).join("\n"),
        },
      ],
      max_tokens: 256,
    }
  );
  return response.response;
}

// Strategy 3: Keep recent + summarized context
async function optimizedContext(
  messages: Message[],
  env: Env
): Promise<Message[]> {
  if (messages.length <= 5) return messages;

  const recent = messages.slice(-3);
  const oldMessages = messages.slice(0, -3);

  const summary = await summarizeHistory(oldMessages, env);

  return [
    {
      role: "system",
      content: `Previous conversation summary: ${summary}`,
    },
    ...recent,
  ];
}
```

### Cost Optimization

<Aside type="tip">
Hermes 2 Pro's small size (7B) means:
- **Lower inference costs** compared to 70B models
- **Faster response times** (crucial for real-time applications)
- **Suitable for high-volume workloads** without breaking budget
</Aside>

Estimate costs:
- Input: ~$0.15 per million tokens
- Output: ~$0.60 per million tokens
- (Prices vary by provider/plan - check Cloudflare pricing)

**Tips to reduce costs:**
1. Use lower `max_tokens` when possible
2. Implement context trimming for long conversations
3. Use JSON Mode (prevents retries for invalid JSON)
4. Cache system prompts using prompt caching

## Common Pitfalls & Solutions

<Details>
<summary>Pitfall: Model doesn't call expected functions</summary>

**Problem**: Hermes isn't calling the functions you defined

**Solutions**:
1. Ensure function descriptions are clear and specific
2. Add examples in system prompt showing when functions should be called
3. Use lower temperature (0.3) for more consistent behavior
4. Verify function names exactly match your definitions

```typescript
// Good: Clear description with guidance
{
  name: "search_api",
  description: "Search our product database. Call this when user asks to find products, compare options, or needs product information.",
  parameters: { ... }
}

// Bad: Vague description
{
  name: "search",
  description: "Search",
  parameters: { ... }
}
```

</Details>

<Details>
<summary>Pitfall: Invalid JSON output with JSON Mode enabled</summary>

**Problem**: Model returns non-JSON even with `response_format` set

**Solutions**:
1. Reduce temperature to 0.1-0.3
2. Make JSON schema as simple as possible initially
3. Add clear examples in system prompt
4. Use `max_tokens` to prevent truncation

```typescript
// Conservative approach
{
  response_format: {
    type: "json_object"
  },
  temperature: 0.1,
  max_tokens: 512
}
```

</Details>

<Details>
<summary>Pitfall: Context window overflow in long conversations</summary>

**Problem**: "Context length exceeded" error

**Solutions**:
1. Implement message truncation (keep last N messages)
2. Summarize old messages periodically
3. Use separate API calls for different conversation threads
4. Monitor token count before requests

```typescript
function countTokens(text: string): number {
  // Rough estimate: 1 token ≈ 4 characters
  return Math.ceil(text.length / 4);
}

async function checkContextFit(
  messages: Message[]
): Promise<{ fits: boolean; usage: number }> {
  const usage = messages.reduce(
    (sum, m) => sum + countTokens(m.content),
    0
  );
  return { fits: usage < 23000, usage };
}
```

</Details>
