Get a working HERMES Trinity system running in 15 minutes with this hands-on guide.

## Prerequisites

- Workers project with Hermes 2 Pro access via Workers AI
- Basic TypeScript knowledge
- `wrangler` CLI installed

## Step 1: Create a Workers Project

```bash
npm create cloudflare -- hermes-trinity-demo
cd hermes-trinity-demo
npm run deploy
```

## Step 2: Set Up the Conductor Agent

The conductor is the central orchestrator. Create `src/conductor.ts`:

```typescript
import { Ai } from "@cloudflare/workers-types";

export interface RoutingDecision {
  agent: string;
  task: string;
  confidence: number;
}

export async function runConductor(
  userRequest: string,
  env: Env
): Promise<RoutingDecision[]> {
  const response = await env.AI.run(
    "@hf/nousresearch/hermes-2-pro-mistral-7b",
    {
      messages: [
        {
          role: "system",
          content: `You are HERMES Trinity Conductor.
          
Analyze requests and decide which agents to use:
- writer: Creates and refines content
- analyst: Analyzes data and generates insights
- executor: Performs tasks and operations

Respond with a JSON array of routing decisions.`,
        },
        {
          role: "user",
          content: userRequest,
        },
      ],
      response_format: {
        type: "json_schema",
        json_schema: {
          type: "object",
          properties: {
            decisions: {
              type: "array",
              items: {
                type: "object",
                properties: {
                  agent: { type: "string" },
                  task: { type: "string" },
                  confidence: { type: "number" },
                },
                required: ["agent", "task", "confidence"],
              },
            },
          },
          required: ["decisions"],
        },
      },
      temperature: 0.3,
    }
  );

  const result = JSON.parse(response.response);
  return result.decisions;
}
```

## Step 4: Create the Main Orchestrator

Create `src/index.ts`:

```typescript
import { Env } from ".";
import { runConductor } from "./conductor";
import { writerAgent, analystAgent } from "./agents";

interface HermesResponse {
  status: "success" | "error";
  result?: string;
  error?: string;
  metadata?: {
    agentsUsed: string[];
    confidence: number;
    executionTime: number;
  };
}

export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    if (request.method !== "POST") {
      return new Response("Send a POST request with JSON body", { status: 400 });
    }

    try {
      const startTime = Date.now();
      const { query } = (await request.json()) as { query: string };

      if (!query) {
        return new Response(JSON.stringify({ error: "Missing query" }), {
          status: 400,
        });
      }

      // Step 1: Conductor decides routing
      const routing = await runConductor(query, env);

      // Step 2: Execute based on routing
      let result = "";
      const agentsUsed: string[] = [];
      let totalConfidence = 0;

      for (const decision of routing) {
        agentsUsed.push(decision.agent);
        totalConfidence += decision.confidence;

        if (decision.agent === "writer") {
          result = await writerAgent(decision.task, env);
        } else if (decision.agent === "analyst") {
          result = await analystAgent(decision.task, env);
        }

        // Quality gate: if confidence too low, flag it
        if (decision.confidence < 0.7) {
          console.warn(
            `Low confidence decision from ${decision.agent}: ${decision.confidence}`
          );
        }
      }

      const executionTime = Date.now() - startTime;

      const response: HermesResponse = {
        status: "success",
        result,
        metadata: {
          agentsUsed,
          confidence: totalConfidence / routing.length,
          executionTime,
        },
      };

      return new Response(JSON.stringify(response), {
        headers: { "Content-Type": "application/json" },
      });
    } catch (error) {
      console.error("HERMES Error:", error);
      const response: HermesResponse = {
        status: "error",
        error: error instanceof Error ? error.message : "Unknown error",
      };

      return new Response(JSON.stringify(response), {
        status: 500,
        headers: { "Content-Type": "application/json" },
      });
    }
  },
} satisfies ExportedHandler<Env>;
```

## Step 6: Add Memory (Optional but Recommended)

Add persistence with Workers KV:

```typescript
interface Message {
  role: "user" | "assistant";
  content: string;
  timestamp: Date;
}

async function storeMemory(
  userId: string,
  message: Message,
  env: Env
): Promise<void> {
  const key = `memory:${userId}`;
  const existing = (await env.KV.get(key, "json")) as Message[] | null;
  const messages = existing || [];
  messages.push(message);

  // Keep last 50 messages
  if (messages.length > 50) {
    messages.shift();
  }

  await env.KV.put(key, JSON.stringify(messages), {
    expirationTtl: 86400 * 30, // 30 days
  });
}

async function getMemory(userId: string, env: Env): Promise<Message[]> {
  const key = `memory:${userId}`;
  return ((await env.KV.get(key, "json")) as Message[]) || [];
}
```

## Common Patterns

### Pattern 1: Content Pipeline

```typescript
async function contentPipeline(topic: string, env: Env): Promise<string> {
  // 1. Analyze topic
  const analysis = await analystAgent(`Research: ${topic}`, env);

  // 2. Write content
  const content = await writerAgent(
    `Based on this research: ${analysis}\nWrite an article about ${topic}`,
    env
  );

  return content;
}
```

### Pattern 2: Multi-turn Conversation

```typescript
async function chat(
  userId: string,
  userMessage: string,
  env: Env
): Promise<string> {
  const memory = await getMemory(userId, env);

  const messages = [
    ...memory.map((m) => ({ role: m.role, content: m.content })),
    { role: "user", content: userMessage },
  ];

  const response = await env.AI.run(
    "@hf/nousresearch/hermes-2-pro-mistral-7b",
    {
      messages,
      temperature: 0.7,
    }
  );

  await storeMemory(userId, {
    role: "user",
    content: userMessage,
    timestamp: new Date(),
  });

  await storeMemory(userId, {
    role: "assistant",
    content: response.response,
    timestamp: new Date(),
  });

  return response.response;
}
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Low confidence decisions | Add clearer agent descriptions in conductor |
| Slow responses | Reduce `max_tokens` or use lower temperature |
| Inconsistent outputs | Increase system prompt specificity |
| Token limits | Implement context trimming for long conversations |
