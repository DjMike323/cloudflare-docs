Marketplace of pre-built connectors for KAI workflows. Use these to connect to external systems without writing custom code.

## Available Connectors

### HTTP / REST APIs

**HTTP Connector**
- GET, POST, PUT, DELETE, PATCH requests
- Custom headers and authentication
- JSON/form data support
- Timeout and retry configuration

```json
{
  "type": "http",
  "action": "post",
  "params": {
    "url": "https://api.example.com/users",
    "headers": { "X-API-Key": "your-key" },
    "body": { "name": "John", "email": "john@example.com" }
  }
}
```

### Databases

**PostgreSQL / MySQL**
- Query data
- Insert/update/delete
- Transactions
- Connection pooling

```json
{
  "type": "database",
  "action": "query",
  "params": {
    "database": "postgres",
    "query": "SELECT * FROM users WHERE email = $1",
    "params": ["{{user_email}}"]
  }
}
```

**MongoDB**
- Find documents
- Insert/update/delete
- Aggregation pipeline
- Bulk operations

```json
{
  "type": "mongodb",
  "action": "find",
  "params": {
    "collection": "users",
    "filter": { "status": "active" },
    "limit": 10
  }
}
```

**Firebase/Firestore**
- Read/write documents
- Batch operations
- Queries
- Real-time listeners

```json
{
  "type": "firestore",
  "action": "set",
  "params": {
    "collection": "users",
    "doc": "{{user_id}}",
    "data": { "name": "{{name}}", "updated_at": "now()" }
  }
}
```

## Creating Custom Connectors

Extend KAI with your own integrations.

```typescript
// 1. Define connector
interface MyConnector extends BaseConnector {
  id: "my_service";
  actions: [
    {
      id: "do_something";
      name: "Do Something";
      params: { input: { type: "string"; required: true } };
    }
  ];
}

// 2. Implement execute method
async execute(
  action: string,
  params: Record<string, any>,
  env: Env
): Promise<any> {
  if (action === "do_something") {
    return await this.doSomething(params, env);
  }
  throw new Error(`Unknown action: ${action}`);
}

// 3. Register with KAI
connectors["my_service"] = new MyConnector();

// 4. Use in workflows
{
  "type": "my_service",
  "action": "do_something",
  "params": { "input": "{{some_value}}" }
}
```

## Connector Configuration

Each connector requires configuration in `wrangler.toml`:

```toml
[env.production.secrets]
# Database
DATABASE_URL = "postgresql://..."

# APIs
SLACK_BOT_TOKEN = "xoxb-..."
STRIPE_API_KEY = "sk_live_..."
SHOPIFY_API_KEY = "..."

# Cloud Storage
AWS_ACCESS_KEY_ID = "..."
AWS_SECRET_ACCESS_KEY = "..."
```

## Performance & Limits

| Aspect | Limit | Notes |
| --- | --- | --- |
| Request timeout | 30 seconds | Per connector call |
| Concurrent connectors | 10 | Per workflow |
| Retry attempts | 3 | Exponential backoff |
| Rate limiting | 100 req/min | Per API key |

3. Document actions and parameters
4. Submit PR with examples
