### Build Your First Agent

Create a custom agent for your domain:

```typescript
// Custom domain-specific agent
export async function myDomainAgent(
  input: string,
  env: Env
): Promise<string> {
  const response = await env.AI.run(
    "@hf/nousresearch/hermes-2-pro-mistral-7b",
    {
      messages: [
        {
          role: "system",
          content: "You are an expert in [YOUR DOMAIN]. Be specific and actionable.",
        },
        { role: "user", content: input },
      ],
      temperature: 0.3,
      max_tokens: 1024,
    }
  );
  return response.response;
}
```

## Phase 5: Optimization & Scaling (Ongoing)

### Continuous Learning

After deployment, monitor these metrics:

- **Learning Progress**: Track Unidad Dos pattern extraction
- **Latency Trends**: P50, P95, P99 should improve over time
- **Cache Hit Rate**: Target > 70% with optimization
- **Token Efficiency**: Reduce tokens/request through batching

### Advanced Topics to Explore

1. **Semantic Caching**
   - Group similar requests
   - Share results across users
   - Expected: 40-50% latency improvement

2. **Batch Processing**
   - Process 10-20 requests together
   - Significant token savings
   - Expected: 60% cost reduction

3. **Hierarchical Conductor**
   - Multi-level routing
   - Specialized sub-conductors
   - Better routing confidence

4. **Distributed Tracing**
   - Track requests across components
   - Identify bottlenecks
   - Debug complex workflows

### Monitoring Dashboard

Create a dashboard tracking:

```
Real-time Metrics:
├── Requests/second (target: 100-500)
├── P95 Latency (target: 1.5-2.5s)
├── Success rate (target: > 98%)
└── Cache hit rate (target: > 70%)

Learning Metrics:
├── Patterns extracted/day
├── Semantic memory size
├── Procedural success rate
└── Routing confidence trend

Cost Metrics:
├── Tokens/request (trending down)
├── Cost/request
├── Cache savings
└── Batch efficiency
```

## Quick Reference Cards

<Details>
<summary>Architecture Quick Reference</summary>

**Conductor (Router)**
- Decides which agent to use
- Uses Hermes 2 Pro for intelligent routing
- Returns confidence score
- Temperature: 0.3 (precise)

**Worker Agents**
- Writer: Content generation (0.6 temperature)
- Analyst: Data analysis with JSON output (0.3 temperature)
- Executor: Task execution (varies)

**Unidad Dos (Memory)**
- Episodic: D1 database, 30-day retention
- Semantic: Learned concepts, embeddings
- Procedural: Workflows that work
- Task State: Current in-progress work

**Storage**
- D1: Persistent learning
- KV: Fast cache (1-hour TTL typical)
- R2: Archive/audit logs

</Details>

<Details>
<summary>Performance Targets</summary>

**Latency**
- P50: 500-800ms (↓ 40% with learning)
- P95: 1.5-2.5s
- P99: 3-5s

**Throughput**
- 100-500 req/sec per instance
- Auto-scales to 1000+ with Workers
- Batch processing adds 40% efficiency

**Success Rate**
- Target: > 98%
- With KAI fallback: > 99%

**Cost**
- ~$3,700/month at 1M requests
- ~$0.0004 per request
- Reduces 60% with batching

</Details>
